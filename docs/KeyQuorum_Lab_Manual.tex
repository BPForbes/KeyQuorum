\section{Where the lab lives}

KeyQuorum Lab is published from \file{lab/} to GitHub Pages and embedded by
bailey-forbes.com. A GitHub Actions workflow tests, builds, and publishes
it from \code{main} on every change. The lab is a sandboxed machine, not a
second implementation of KeyQuorum: it must never reimplement quorum,
custody, approval, visibility, bridge, or delivery rules, or add a gate of
its own in front of them --- if the CLI would allow something on a real
machine, the lab allows it too.
