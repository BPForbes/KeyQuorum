  - ConfigMap {{ .Values.trust.existingConfigMap }} with {{ .Values.trust.certificateKey }}{{ if .Values.trust.revocationListKey }} and {{ .Values.trust.revocationListKey }}{{ end }};
  - Secret {{ .Values.secrets.relayKey.existingSecret }} with the relay private key under "{{ .Values.secrets.relayKey.key }}";
  - Secret {{ .Values.secrets.mongodbUri.existingSecret }} with the connection string under "{{ .Values.secrets.mongodbUri.key }}".

Check readiness (store reachable) and the provider identity from a client:
  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
  keyquorum --db ./me.sqlite loadkey --url https://{{ .Values.ingress.host }} --bundle customer.kqkey --slot ./usb=M.S

The provider-root private key and the kql_ operator lock are never given to
the cluster. Mint customer keys from an operator workstation or a one-off
Job, as docs/operator/relay-deployment.md describes.
